
# Machine Learning & Deep Learning

A collection of machine learning and deep learning implementations, focusing on neural networks, computer vision, and AI-based robotic control using Raspbot2.

This repository contains practical implementations developed through machine learning coursework and hands-on robotics experiments.

## Overview

The repository covers three main areas:

- **Machine Learning** — Regression, classification, and clustering algorithms
- **Deep Learning** — Neural networks, CNN architectures, and image recognition
- **AI Robotics** — Camera-based perception and robot control using Raspbot2

## Tech Stack

- **Language:** Python
- **Deep Learning:** PyTorch
- **Machine Learning:** NumPy, Scikit-learn
- **Computer Vision:** OpenCV, Pillow
- **Model Deployment:** ONNX, ONNX Runtime
- **Hardware:** Raspberry Pi, Raspbot2
- **Development:** Jupyter Notebook

## Projects & Practice

| Topic | Description |

### 3. Raspbot2 AI Robotics

Hands-on experiments integrating deep learning models with the Raspbot2 robotic platform.

**Main Objectives**
- Camera-based image acquisition
- Real-time image processing
- Deep learning-based object recognition
- Robot movement and motor control
- Integration of AI perception with robotic systems

**Development Workflow**

```text
Raspbot2 Camera
      |
      v
Image Acquisition
      |
      v
Image Preprocessing
      |
      v
Deep Learning Model
      |
      v
Prediction / Recognition
      |
      v
Robot Control
```

The goal is to build an AI-based robotic system that combines visual perception with physical robot control.
